# 🏡 Gaon Bazaar – Online Village Marketplace

**A Digital Marketplace Connecting Local Sellers with Customers**

🌐 **Live Demo:** https://gaon-bazaar.pages.dev/

💻 **GitHub Repository:** https://github.com/Sanjanakumarii/Gaon-Bazar-Project

## 📌 About the Project

Gaon Bazaar is an online marketplace platform designed to connect rural sellers with customers. It helps local shopkeepers showcase their products online and allows customers to order products from nearby shops.

The platform aims to promote rural businesses through digital technology.

## 🚀 Key Features

- Customer Registration and Login
- Seller Registration and Shop Management
- Product Listing and Management
- Location-Based Shop Discovery
- GPS and Map Integration
- Shopping Cart and Order Placement
- Order Tracking and Status Updates
- English, Hindi and Hinglish Language Support
- Mobile-Friendly Interface

## 🛠️ Technologies Used

- Next.js
- React
- TypeScript
- Node.js
- SQLite
- Drizzle ORM
- CSS
- Leaflet Maps
